# Reproducibility notes

## Environment

Python 3.12; `requirements.txt` pins the library versions behind the reported numbers (pandas 2.2.3, numpy 1.26.4, scipy 1.15.2, scikit-learn 1.6.1, matplotlib 3.10.1). `requirements-lock.txt` is the exact environment. CPU only.

## Data snapshot

`data/raw/` holds the World Bank and OWID extracts downloaded on 2026-06-24. Run every stage with `HSR_OFFLINE=1` (the Makefile default) to reuse them; without the flag the download modules re-fetch from the APIs. The GHS raw file is fetched by `scripts/fetch_data.py` and hash-verified.

## Order of operations

```bash
python scripts/fetch_data.py
HSR_OFFLINE=1 python experiments/run_minimal_pipeline.py      # Stage 1
HSR_OFFLINE=1 python experiments/run_stage2_hsr_convert.py     # Stage 2
HSR_OFFLINE=1 python experiments/run_stage3_reviewer_proof.py  # Stage 3
HSR_OFFLINE=1 python experiments/run_stage4_final_evidence.py  # Stage 4
python -m revision_analysis.run_all                            # sensitivity, models, baselines, statistics, figures
python scripts/round3_publication_assets.py                    # manuscript figures/tables
python scripts/verify_claims.py
```

Each stage depends on the previous stage's tables. Stage 2 defines the baseline scoring frame with World Bank preparedness proxies only; GHS 2019 enters in Stage 4 (`config/indicator_blocks.yml: baseline_blocks.include_ghs_2019`).

## Verification targets

`python scripts/verify_claims.py` checks: 193 scoring countries; 106 OWID validation countries; profile counts 20/23/20/16/27; ridge single-split CV RMSE 1764.98; 189 GHS-matched countries; label triage 41/38/107; cross-evidence agreement/Spearman 0.972/0.996, 0.642/0.660, 0.651/0.654; and, when `results/revision/revision_numbers.json` is present, 89 threshold-invariant countries and a repeated-CV ridge RMSE of 1759.2.

## Determinism

Seeds are fixed (20260624 for the pipeline, 20260921 for the revision analyses). Repeated runs on the same environment reproduce the tables to floating-point precision; tree-based models can differ at the last digit across BLAS builds.

## Excluded large intermediates

`results/tables/pipeline_grid_results.csv` and `pipeline_rank_correlations.csv` (about 25 MB) are regenerated by Stage 1/2 and are git-ignored.
