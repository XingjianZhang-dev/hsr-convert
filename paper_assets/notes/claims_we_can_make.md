# Claims We Can Make

- HSR-Convert separates pre-shock potential capacity from shock-realized conversion efficiency.
- The methodological contribution is the capacity-to-resilience conversion layer, not a generic new MCDM ranking method.
- Official GHS 2019 evidence is integrated as a provenance-controlled preparedness sensitivity when loaded; 2021 GHS values are not used as pre-shock features.
- Life expectancy loss provides a programmatic secondary outcome for cross-evidence stability checks.
- Stable country labels can be distinguished from evidence-dependent and data-limited labels.
- Data-limited labels are an explicit uncertainty output: HSR-Convert does not force country claims when evidence support is weak.
- WHO pulse evidence is provenance-controlled; if no legitimate country-level file is present, the paper can report that service-disruption validation was not performed.
